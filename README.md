# CodeAlpha Web Scraping Project

## Project Overview
This project is part of the CodeAlpha Data Analytics Internship.

The objective of this project is to collect book information from the Books to Scrape practice website using Python.

## Website
https://books.toscrape.com/

## Technologies Used
- Python
- Requests
- BeautifulSoup
- CSV

## Data Collected
The project extracts the following information:
- Book Name
- Price
- Rating
- Availability

## Project Files
- `web_scraping.py` – Python source code.
- `all_books_data.csv` – Scraped book dataset.

## How to Run
1. Install Python.
2. Install required libraries:

   `pip install requests beautifulsoup4`

3. Run the Python file:

   `python web_scraping.py`

4. The scraped data will be saved in `all_books_data.csv`.

## Learning Outcomes
- Understanding Web Scraping.
- Extracting data using BeautifulSoup.
- Sending website requests using Requests.
- Saving extracted data into CSV files.
